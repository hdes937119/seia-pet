# 自用專屬 Gemini 雙子星貓「美國大豆包」桌寵實作計劃（完整記憶與自主探索版）

為滿足您的高效自用需求，本計劃專注於五大核心能力：
1. **個性調音台（性格拉桿與提示詞）**
2. **LINE / Gemini 直覺雙模式對話介面**
3. **螢幕畫面即時感知與主動搭話（Screen Vision）**
4. **待機自主探索與影片推薦系統（聯網探索與私房筆記）**
5. **關鍵字動態衰變與永久記憶系統（Memory Decay & Notebook Engine）**

> [!IMPORTANT]

- **新功能 1：待機自主探索與影片推薦（Autonomous Idle Explorer）**
  - 當主人處於待機或閒置狀態時，雙子星貓會根據當前微性格（如毒舌、搞笑、知性、音樂狂熱）自主進行搜尋（利用 Gemini Google Search 或二創推薦資料庫）。
  - 她會將發現的有趣影片與自己的辛辣/可愛評論記錄在「貓貓的摸魚小手帳」中。
  - 當您回來聊天或主動詢問「最近有什麼好看的？」時，她會如數家珍地向您安利推薦；亦可設定為發現神作時主動彈出小氣泡分享。
- **新功能 2：關鍵字動態衰變與永久記憶系統（Keyword Decay & Memory Core）**
  - **記憶權重演算法**：
    - 每次對話中自動提取主人的「喜好關鍵字」（如特定遊戲名、喜歡的食物、編程語言、常聊話題）。
    - 關鍵字帶有「熱度值（0-100）」、「提及次數」與「時間衰變因子（Decay Factor）」。
    - 少用的關鍵字隨時間自然衰減，熱度歸零後移入遺忘區；
    - 頻繁出現或強烈偏好的關鍵字達到「永久鎖定閾值（例如提及 $\ge 4$ 次或熱度 $\ge 80$）」，即自動晉升並永久寫入「永不遺忘筆記本」，永不被衰變刪除。
  - **透明可視化筆記本**：
    - 介面提供專屬「貓貓的記憶小本本」分頁，可隨時查看當前活躍關鍵字、正在衰變的詞，以及已永久銘記的喜好設定。
  - **性格驅動對話**：
    - 多維度微性格拉桿（毒舌 ⟷ 體貼、聒噪 ⟷ 恬靜、搞笑整活 ⟷ 認真客觀、傲嬌度）與自填每日提示詞。
- **直覺對話與發聲**：
  - LINE 經典聊天與 Gemini 現代聊天雙模式，搭配 Web Speech API 即時語音朗讀。

## 1. 產品概述與核心概念

- **自用定位**：一位真正生活在您電腦上的 AI 貓娘伙伴——平時會偷看你在幹嘛並開口吐槽，待機時會自己上網摸魚找好笑影片，且具備如同真實朋友般的記憶遺忘曲線，越常聊的話題她記越牢。
- **核心場景**：
  - **工作/遊戲主動陪伴**：透過螢幕共享感知您當前的畫面（打遊戲殘血、看搞笑短片、回 LINE 訊息），即時語音吐槽或加油。
  - **閒置時的自主生活**：您暫離去泡咖啡，回來看到她留言：「剛剛閒著無聊看了一支超下飯的搞笑精華，筆記本記下了，等你想看再問我喵～」。
  - **長效記憶反饋**：因為您連續三天提到想吃拉麵，她便將「拉麵愛好者」永久寫入筆記，日後自主推薦或聊天都會自然帶入。

## 2. 使用者體驗與介面設計

### 關鍵功能版塊
1. **主對話介面（LINE 模式 / Gemini 模式雙向切換）**：
   - **LINE 風格**：經典深綠頭頂列、白色/綠色圓角氣泡、「已讀」標籤、時間戳記。
   - **Gemini 原生風格**：星芒流光標識、極簡暗色質感卡片、清晰 Markdown 支援。
2. **螢幕即時追蹤控制條（Screen Vision Bar）**：
   - 瀏覽器原生 `getDisplayMedia` 視窗授權；
   - 包含即時畫面預覽縮圖、當前追蹤活動識別標籤（遊戲中 / 追劇中 / 聊天中 / 專注工作）。
3. **個性調音台（Personality & Prompt Console）**：
   - 毒舌度、聒噪度、幽默度、傲嬌度 4 條平滑滑桿；
   - 「每日微性格自訂提示詞」輸入框與一鍵預設套餐（毒舌傲嬌貓娘、溫柔治癒甜心、整活大豆包、知性技術宅）。
4. **記憶筆記本與衰變儀表板（Memory Decay & Notebook）**：
   - 🌟 **永久記憶區**：已達高頻閾值的核心喜好與習慣，永不遺忘。
   - ⏳ **近期活躍區**：當前正在關注的話題，附帶熱度進度條與倒數衰變指示。
   - 🗑️ **已遺忘區**：長時間未提及已自然淡出的記憶（支援手動一鍵喚醒或刪除）。
5. **待機推薦清單（Cat's Video & Topic Backlog）**：
   - 貓娘在閒置時自主搜集並寫下的私房影片筆記、觀影評論與推薦理由。

### 關鍵字記憶衰變演算法細節
```typescript
interface MemoryKeyword {
  id: string;
  keyword: string;           // 喜好關鍵字 (例如 "Steam特惠", "黑神話悟空", "無糖綠茶")
  category: 'preference' | 'habit' | 'game' | 'topic';
  frequency: number;         // 提及次數
  strength: number;          // 記憶強度 0-100
  lastMentioned: number;     // 最後提及時間戳記
  isPermanent: boolean;      // 是否已鎖定為永久記憶 (strength >= 80 或 frequency >= 4)
  notes?: string;            // 貓娘對該特徵的評語
}
```

## 預計實作步驟

1. **基礎對話與雙模介面**：完成 LINE 經典介面與 Gemini 簡約介面，支援連續對話與 Web Speech 語音播報。
2. **個性調音台**：實作 4 維個性拉桿（毒舌、聒噪、幽默、傲嬌）與自訂微性格提示詞組裝。
3. **螢幕即時追蹤（Screen Vision）**：整合 `getDisplayMedia` 視窗捕獲與定時視覺分析，實現看懂打遊戲、看片與回 LINE 並主動搭話。
4. **待機自主探索與推薦模組**：建立閒置計時器，觸發搜尋影片/主題推薦，並存入貓娘摸魚手帳。
5. **關鍵字動態衰變與永久筆記本**：實作艾賓浩斯記憶衰變演算法、自動關鍵字萃取、記憶筆記本面板與持久化儲存。
6. **編譯測試與端到端驗證**：確保視窗分享、語音朗讀、自主搜尋與記憶演算法全部正常運作。
